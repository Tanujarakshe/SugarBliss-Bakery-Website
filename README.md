# SugarBliss — Bakery Website

A responsive bakery landing page built with React, Vite, HTML and CSS.

## Features
- Responsive navigation with mobile menu
- Hero section, featured products, brand story and contact section
- Product cards with hover effects
- Contact form with name, email and message validation
- Responsive layouts using Flexbox, CSS Grid and media queries
- Semantic HTML and accessible labels

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
1. Extract the ZIP.
2. Open the `SugarBliss` folder in VS Code or another code editor.
3. Open a terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Create production build
```bash
npm run build
```

## Customize before publishing
- Replace the sample phone number and Pune location if needed.
- Update product names, prices and photos.
- The contact form currently validates input in the browser; it does not send messages to a server.
- Product and hero photos are loaded from Unsplash, so internet access is required to display them.
